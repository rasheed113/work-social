# Private Product Documentation

The detailed Work House roadmap, product WHY, architecture direction, and strategic documentation are maintained in the private repository:

**`rasheed113/work-social-private`**

Repository: https://github.com/rasheed113/work-social-private

## Documentation policy

- Keep product strategy, blueprints, unreleased plans, architecture decisions, and other sensitive planning documents in the private repository.
- Do not copy the private roadmap into this public application repository.
- When Work House implementation work is planned, consult the current roadmap in `work-social-private` first and follow its latest direction.
- Update the roadmap/documentation in `work-social-private`, not here.
- Public repository documentation should contain only information that is intentionally safe to expose publicly.

The private repository is the source of truth for the Work House roadmap and strategic product documentation.
